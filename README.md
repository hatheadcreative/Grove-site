# Grove Music School — website

Static site for Grove Music School, built by Hathead Creative.

- **Build:** `node build.mjs` (no dependencies to install)
- **Output:** `dist/`
- **Hosting:** Hostinger Web App, deployed from `main`

Staging only, not indexed by search engines.
